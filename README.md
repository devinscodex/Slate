# Slate

A suckless PDF editor. View, annotate, merge/split, redact, sign, fill forms —
composed from proven libraries (PyMuPDF, pikepdf, pyHanko), not a reimplemented
PDF engine. Built to replace Foxit Pro / Adobe Pro for daily use.

Design rationale, library choices, and the build/verification order: see
`DESIGN.md`.

## Setup

```
make venv
```

## Run

```
make run
```

## Test

```
make test
```
