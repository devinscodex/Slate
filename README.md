# Slate

A small, no-bloat PDF editor. View, annotate, merge/split, redact, sign, fill forms —
composed from proven libraries (PyMuPDF, pikepdf, pyHanko), not a reimplemented
PDF engine. Built to replace Foxit Pro / Adobe Pro for daily use.

A byproduct of Cairn, an AI development harness — built to be the document
reader/editor we always wanted. Adobe is bloated and predatory, Foxit is
mediocre, Sumatra is nice but limited. Slate is another free, open-source
option, proof of how good FOSS can really be.

Design rationale, library choices, and the build/verification order: see
`DESIGN.md`.

## Setup

```
make venv
```

## Run

```
make run
```
