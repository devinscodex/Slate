Slate -- what it does

rev01 -- 2026-10-29 -- a plain-English guide to every feature in the current build. Companion to slate-architecture-rev01.html (the module map, written for developers). This page is for anyone using the app.

Overview

Slate is a PDF editor. You use it to read, mark up, fix, and protect PDF files on your own computer. Slate does not send your files anywhere. Every feature below runs on your machine.

Glossary

PDF
A document file format that looks the same on every computer.
Redaction
Permanently removing text or an image from a page, not just covering it with a black box. A real redaction cannot be undone or reversed.
OCR
Optical Character Recognition. It reads the text in a scanned image and adds a hidden, searchable text layer under the image.
Digital signature
A cryptographic stamp that proves a file has not changed since it was signed.
Theme
A set of colors for the app's own screen, not the document.
Tab
One open document. Slate can hold several tabs in one window.

1. Viewing a document

  • Zoom in, zoom out, or Fit Width (the page always fills the window's width).
  • Slate finds each page's real content area and can trim blank margins (Crop to Content).
  • Move through pages one at a time, jump to a page number, or jump to the last page.
  • A bookmarks panel shows the document's own table of contents, if it has one.
  • Continuous scroll: pages flow one after another, like a long scroll.
  • Book view: several pages show side by side in one row, like an open book.
  • Large documents stay fast to scroll. Slate only draws the pages near your current view.
  • Open more than one file at once. Each file gets its own tab in the same window.
  • Opening a second file reuses the same window and adds a tab, instead of opening a new window. This can be turned off in Settings.

2. Marking up a page

  • Highlight text with a see-through color marker.
  • Add a floating text note anywhere on a page.
  • Draw freehand ink marks or a rectangle shape.
  • Stamp a page (for example, "Approved").
  • Find text anywhere in the document and jump between matches.

3. Editing a document

  • Edit existing body text in place. Slate tries to match the original font. It warns you if the new text will not fit.
  • Fill in PDF form fields: text boxes, checkboxes, radio buttons, dropdowns, and lists.
  • Merge several PDFs into one file, or split one PDF into separate files per page.
Rotate, delete, move, and insert pages are built and tested, but not yet wired into the on-screen menus in this build.

4. Redacting sensitive content

  • Permanently remove text, images, and drawings from a page. This is a real redaction, not a black box drawn on top. Hidden document metadata is cleared too.
  • Scan a document for likely Social Security numbers, bank routing numbers, bank account numbers, and credit card numbers. Slate flags what it finds so you know what to review.
  • Scan an entire folder of PDFs for the same patterns in one pass.
  • If a page has no searchable text (for example, an un-OCR'd scan), Slate flags it as "unscannable" instead of silently calling it clean.

5. Protecting a document

  • Password-protect a PDF. You set a password readers must enter, and a separate owner password that controls what they're allowed to do (such as printing).
  • Open a PDF someone else password-protected, by entering the password.
  • Apply a digital signature. Slate can generate a throwaway certificate for you, or use a real company-issued one.
  • Check whether a PDF is already signed, and confirm an existing signature is still valid.
  • Lock the text-editing feature behind a passphrase on your own machine. This is a convenience lock for your own desk, not real security against someone with full access to the computer.

6. Scanning and converting files

  • Scan paper into a PDF.
  • OCR scanned pages, so you can search, select, and copy their text, with no change to how the page looks.
  • Convert a web page (HTML) to PDF, rendered through a real browser so it looks right.
  • Convert a PDF to Markdown text (keeps headings, bold text, and bullet lists) or to plain text.
  • Export PDF pages as image files, or build a new PDF from a set of images.
  • Open an image, EPUB, HTML, or text file directly. Slate converts it to PDF automatically.
  • Fix a known EPUB e-book bug that garbles text, with no change to your original file.

7. Making Slate your own

  • Six built-in color themes, light and dark, including a Martin Energy Group brand theme ("Basic").
  • A full color editor: change any theme's colors and save your changes, or save a whole new theme under its own name.
  • Your theme choice, including any hand-tuned colors, is still there the next time you open Slate.
  • Colorize Pages: optionally tint the document itself to match the app's theme.
  • A separate text-size control scales the whole app, menus included -- this is different from zooming a document's pages.
  • A Recent Files list remembers your last 10 files, and quietly drops any that no longer exist.
  • Slate reopens at the same window size, position, tabs, and zoom level you left it at.

8. Staying up to date

  • Slate can check for a new version automatically when it starts, or you can check by hand from the About screen.
  • On Windows, Slate can download a new version itself. It checks the download against a published checksum before ever running it.
  • You choose when the update actually happens: right now, the next time you close Slate, or the next time you open it.
